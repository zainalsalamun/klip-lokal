# Identitas Kelip Studio

Nama resmi produk: **Kelip Studio**. Dibaca “Kelip Studio”. Wordmark **k✳lip.** mempertahankan logo yang dipilih pengguna; simbol ✳ mewakili huruf **E**, dan tulisan STUDIO mendampingi logo. Nama tekstual dan label aksesibilitas memakai Kelip Studio.

Tagline kerja: **Video panjang. Momen pilihan.**

Deskripsi: studio video pendek dengan AI lokal, untuk memilih kandidat klip, menyiapkan subtitle/caption serta ekspor watermark dan thumbnail. Hasil otomatis tetap perlu ditinjau.

Warna dasar: teks#222722, hijau zaitun#71862e, latar krem#f6f5f1, aksen tombol#d8ed64. Logo tidak dibuat ulang sebagai gambar AI; glyph dan tipografi existing dipertahankan.

## Fokus pengembangan

Versi lokal menjadi prioritas. Tahap terdekat: kualitas potongan/transkripsi/crop, editor koreksi manual, ekspor yang andal, serta kemudahan instalasi dan penggunaan laptop8GB. Layanan online, akun, pembayaran dan langganan belum menjadi scope implementasi aktif.

Nama folder/repository klip-lokal, identitas health API dan label launcher tetap merupakan identifier teknis existing untuk kompatibilitas. Penggantian nama produk tidak memindahkan data atau mengubah kontrak integrasi tersebut.
